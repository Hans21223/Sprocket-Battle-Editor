Sprocket Battle Editor 0.18.2 - for Sprocket 0.2.55.5 and 0.2.56 (Beta)
https://github.com/Hans21223/Sprocket-Battle-Editor

INSTALL
Needs the Sprocket Mod Loader (BepInEx 6 IL2CPP). Add the zip in Sprocket Mod Manager, or copy its BepInEx folder
into the Sprocket folder. This package contains Battle Editor only. Install Map Framework separately to add
Ambush, The Crossroad, Silent Border, Sandbox and Sandbox (Low performance), or to import your own map sources.

Compiles against both Sprocket 0.2.55.5 and 0.2.56 interop; offline regression checks pass. Parts are still
untested in game (see the README). No game files or loader files are included.
With the optional Sprocket Mod API installed, F9 and F10 can be rebound in its keybinding window.

USE
Open Edit battle from the main menu to create or load a battle. F10 opens the command view during a battle.
Time of day in the Tanks panel and saved battle menu chooses Map default, Dawn, Morning, Noon, Afternoon,
Sunset or Night. Save keeps the choice for play, sharing and replays. Map default restores authored lighting.
Quick battle and Gauntlet setup offer the same choices. Gauntlet keeps its choice between rounds and on resume.
Other times give a custom map their own sky under the game's exposure and fog; its lamps and lit windows shine
only at Dawn, Sunset and Night. Fog None is a clear view, no haze.
Your designs, saved battles and replay files stay in the normal user folders; none are included in this package.
